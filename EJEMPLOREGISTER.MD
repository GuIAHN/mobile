# Project Brief: GuIA Automotriz

## 1. Project Overview
**GuIA Automotriz** is a high-performance mobile ecosystem designed to bridge the gap between vehicle owners, specialized mechanics, and spare parts stores. The platform focuses on precision engineering, trust, and speed, providing a "digital garage" experience for automotive maintenance and repair.

## 2. Brand Identity & Visual Language
The visual identity has evolved from a "Noir" aesthetic to the **Veloce Automotive System**, a sophisticated, high-contrast light theme characterized by "Clean Garage" and "Precision Engineering" principles.



## 3. Core User Personas & Journeys
### A. The Vehicle Owner (Consumer)
*   **Onboarding:** A clean, 3-step swipe-based introduction (Parts, Mechanics, Digital Garage) before reaching the login.
*   **Registration:** Simple multi-step flow (Basic info -> Car Brand -> Car Model -> Garage setup).
*   **Request Flow:** Create a service/parts request and receive multiple competing offers from shops and mechanics.
*   **Dashboard:** A simplified, non-scrolling home screen for rapid filtering between Parts, Mechanics, and Workshops.

### B. The Specialized Mechanic (Independent Pro)
*   **Registration:** Professional onboarding with specialty selection (Engine, Brakes, Electronics, etc.) and experience verification.
*   **Navigation:** Unified "Back/Next" button system, moving away from standard bottom bars during the registration process.

### C. The Spare Parts Store / Workshop (Business)
*   **Registration:** Business data entry, location mapping, and "Inventory DNA" setup.
*   **Inventory DNA:** A dynamic repeatable flow (Category -> Sub-categories -> Brands) to build a detailed business profile.

## 4. Key Functional Requirements
*   **Interactive Backgrounds:** Integration of WebGL Shaders and Three.js for high-end visual engagement on entry points like Login.
*   **Dynamic Offers:** Real-time bidding/offer system where users compare price, delivery speed, and quality.
*   **Smart Search:** A compact home interface designed for high-speed utility without vertical scrolling.
*   **Digital Garage:** Centralized management of multiple vehicles, service history, and maintenance alerts.

## 5. Technical Specification
*   **UI Framework:** Flutter-optimized designs.
*   **Theming:** Centralized Veloce theme with full support for Light Mode (primary) and Legacy Dark Mode.
*   **Motion:** Use of GLSL Shaders for interactive background effects.
*   **Navigation:** Custom multi-step wizard components for all professional registration flows.

## 6. Success Metrics
*   **Onboarding Completion:** Conversion rate from first swipe to successful login.
*   **Marketplace Efficiency:** Average time from user request to first store offer.
*   **User Retention:** Number of vehicles active in the "Digital Garage" per user.
