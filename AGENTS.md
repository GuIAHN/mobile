# Project guidance

## UI/UX requirements

- For every task that creates, reviews, or changes UI/UX, visual design, navigation, layout, typography, color, interaction, motion, accessibility, or UI states, always invoke and follow both `$ui-ux-pro-max` and `$frontend-design` before proposing or implementing changes.
- Treat `DESIGN_SYSTEM.md` as the current project source of truth. If a skill recommendation conflicts with it, explain the trade-off and obtain user approval before changing the system.
- This is a Flutter mobile application. Use the Flutter stack guidance from `$ui-ux-pro-max` and apply mobile platform conventions rather than web-only rules.
- Before declaring UI work complete, verify loading, error, empty, and data states; accessible contrast; 44 pt / 48 dp touch targets; text scaling; safe areas; reduced motion; and representative small and large phone widths.
